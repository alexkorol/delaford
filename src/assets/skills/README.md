# Starter skill art

The six 128px WebP files are production crops from
`source/verdigris-starter-skills-generated.png`. The source sheet is a 3x2
grid in quickbar order:

1. Bronze Arc
2. Ghostroad Step
3. Cinder Fan
4. Rimebreak
5. Cairn Ward
6. Dawn Rite

The sheet was generated with the built-in image generator as authored 32-bit
pixel-art ARPG icons: blackened bronze, ochre gold, verdigris teal, dark
charcoal backgrounds, no text or emoji styling. Production crops are 128x128,
encoded as WebP at quality 92.
