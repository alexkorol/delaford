# Verdigris mining nodes

These project-local 32×32 sprites were generated with OpenAI's built-in image
generation workflow on 2026-08-13, then chroma-keyed, palette-reduced, and
downscaled with nearest-neighbour sampling:

- `rock-depleted.png`
- `rock-copper.png`
- `rock-tin.png`

The legacy `objects.png` resource row was used only as a silhouette/style
reference. The production atlas builder appends these files after the stable
DCSS/RLTiles entries.

Prompt summary: three isolated, equally scaled, three-quarter/top-down fantasy
RPG pixel-art rock outcrops on a flat green key background; depleted slate,
warm copper seams, and cool silver-blue tin seams; hard pixel edges, upper-left
light, no floor, shadows, labels, tools, characters, grid, or watermark.
